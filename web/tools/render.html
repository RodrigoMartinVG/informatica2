Imágenes de las seis formas, generadas desde los datos

Esta página arma cada hongo en 3D con las medidas promedio del Excel y el color y la superficie más frecuentes, y lo fotografía con una luz de estudio. Para regenerar las imágenes del informe:

  1. Desde la raíz del repo, levantar el receptor: python3 web/tools/save_server.py
  2. Abrir esta página desde el servidor del informe: http://localhost:8765/web/tools/render.html. Las imágenes se guardan en web/img/render/.

Sin el receptor, cada imagen se puede descargar a mano con clic derecho.
